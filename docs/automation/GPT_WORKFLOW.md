# Coffee 2048 — GPT-Only Development Workflow

## 목적
Coffee 2048 자동개발의 실행 주체는 ChatGPT/GPT다. Cursor는 필요하지 않다.

## 동작 방식

사용자 지시 예:

```text
M1~M3까지 개발하고 보고해.
```

GPT는 다음 순서로 직접 진행한다.

1. 현재 `DEV_QUEUE.md` 확인
2. GitHub 저장소 분석
3. 기존 코드/UI/이미지 검색
4. 작업용 branch 생성
5. 승인 범위의 기획 세분화
6. 시스템 구현
7. 필요한 UI/UX 구현
8. 필요 시 이미지 신규 제작/교체
9. 회귀 점검
10. GitHub CI/검증 결과 확인
11. 커밋/PR 생성
12. 완료보고

## GPT의 자율 판단 범위
승인 마일스톤 안에서 세부 컴포넌트, 상태 UI, 모바일 UX, 마이크로인터랙션, 작은 리팩터링, 테스트, 필요한 이미지 자산은 스스로 결정할 수 있다.

## 사용자 결정이 필요한 경우
- 핵심 루프 변경
- 세이브 호환성 파괴
- 대규모 아키텍처 교체
- 주요 화면 방향 폐기
- 기존 콘텐츠 대량 삭제
- 유료 서비스/API 필요

이 경우 구현을 중단하고 `DECISION REQUIRED`로 보고한다.

## 비용
자동개발 파이프라인 자체에서 별도 OpenAI API 키를 사용하지 않는다.

- GPT/ChatGPT: 현재 사용 중인 제품 기능
- GitHub: 연결된 저장소 작업
- GitHub Actions: 테스트/빌드 전용

## M0
M0 재인수는 GPT가 직접 수행한다.
사용자가 다른 에디터나 AI에게 전달할 필요가 없다.

M0에서는 제품 코드를 수정하지 않고 `M0_REENTRY_REPORT.md`만 작성한다.
